# Timecycle modifiers

| Modifier | Uses |
|---|---|
| `spectator1` through `spectator10` | 225, then 75 each |
| `CAMERA_secuirity_FUZZ` | 114 |
| `CAMERA_secuirity` | 97 |
| `mp_x17dlc_int_02_vehicle_avenger_camera` | 45 |
| `DLC_mp2023_02_Maze_Shad` | 42 |
| `mp_bkr_ware03_upgrade` | 40 |
| `mp_bkr_ware02_upgrade` | 40 |
| `INT_smshop_inMOD` | 30 |
| `Yacht_Mission_ThunderRain` | 18 |

**Note the misspelling** in `CAMERA_secuirity` — it must be reproduced exactly.
That pair is what gives CCTV its look; combine with the `SECURITY_CAM` scaleform
and `MP_CCTV_SOUNDSET`.

The telescope uses a timecycle modifier too — see [telescope.md](../features/telescope.md).
