# ATM

**Source:** `atm_trigger.c` (112K)

A dedicated **`ATM`** scaleform and a small script. Probably the single easiest
UI-bearing system to port in the whole repo.

The `trigger` naming matches `laptop_trigger.c` — both are prop-triggered
interactions using the same object-brain idea as the `ob_*` family.
