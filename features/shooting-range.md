# Shooting range

**Source:** `range_modern.c` (2.5M), `range_modern_mp.c`

- Anim dicts `mini@shoot_range`, **`mini@ears_defenders`** (putting on ear
  protection)
- Scaleforms `COUNTDOWN`, `MP_BIG_MESSAGE_FREEMODE`, `SC_LEADERBOARD`

The ear-defenders animation is a nice touch that most custom range scripts skip.
